# 🍼 Victory Little Angels

Kenya's trusted baby shop — diapers, clothing, toys, strollers, and more. Quality products, fair prices, fast delivery.

## 🌐 Live Site

[Visit Victory Little Angels](https://YOUR-USERNAME.github.io/victory-little-angels/)

## 🛠️ Built With

- HTML5, CSS3, Vanilla JavaScript
- Firebase (Authentication + Firestore)
- Hosted on GitHub Pages
- Product images via ImgBB

## ✨ Features

- 🛍️ Product catalog with filters, sorting & search
- 🛒 Shopping cart (persists across sessions)
- 🔐 Firebase Authentication (signup / login)
- 💳 Checkout with M-Pesa / Card / Cash on Delivery
- 👤 User account dashboard with order history
- 🔧 Admin panel (manage products, orders, messages)
- 📱 Fully responsive on mobile
